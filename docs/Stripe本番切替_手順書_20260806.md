### ⚠️ 片付け（必須）

テスト店舗には**14日タイマー付きの本番契約**が付いている。放置すると
**トライアル終了日に本物の請求書が発行され、請求メールが飛ぶ**。

1. **Stripeで契約をキャンセル**（これで請求の危険は消える。顧客レコードは残っていても無害）
2. DBの店舗を関連データごと削除 → その後アカウントを削除（**店舗→アカウントの順**。
   逆は `stores.owner_user_id → auth.users` のFK制約で失敗する）

`stores` の子テーブルには **ON DELETE CASCADE が無い**ので、店舗を消す前に
`store_id` を持つ各テーブルから消す必要がある。SQLは下記。

⚠️ **メールアドレスで消さないこと。** 打ち間違いや似たアドレスで**本物の店舗を消す事故**になる。
必ず①で目視してから、②にそのIDを貼る。

```sql
-- ① 新しい順に5件出す。テスト店舗の行を目で確かめて id をコピーする
SELECT id, name, owner_email, created_at FROM stores
ORDER BY created_at DESC LIMIT 5;

-- ② 関連データごと削除（store_id を持つ全テーブルを自動で回す）
--    ↓の 'ここに①でコピーしたUUID' を必ず貼り替えてから実行する
--    安全装置3枚: ①本番UUIDを名指しで拒否 ②店舗名が「テスト」で始まること
--                ③DOブロック全体が1トランザクション（途中で止まれば全部巻き戻る）
DO $$
DECLARE target uuid := 'ここに①でコピーしたUUID';
        tbl text;
        nm text;
BEGIN
  -- ① 本番店舗(KYOUKANO)を名指しで拒否
  IF target = '4cb3383a-31e5-408a-9f75-60a25943ac4d'::uuid THEN
    RAISE EXCEPTION '本番店舗(KYOUKANO)です。中止しました。';
  END IF;

  SELECT name INTO nm FROM stores WHERE id = target;

  -- ② 該当なし(NULL)も、テスト以外の名前も中止
  --    ※全角/半角の数字ゆれで誤爆しないよう前方一致で見る
  IF nm IS NULL OR nm NOT LIKE 'テスト%' THEN
    RAISE EXCEPTION '想定外の店舗です（id=% / name=%）。安全のため中止しました。', target, nm;
  END IF;

  FOR tbl IN SELECT table_name FROM information_schema.columns
             WHERE column_name = 'store_id' AND table_schema = 'public'
               AND table_name <> 'stores'
  LOOP
    EXECUTE format('DELETE FROM %I WHERE store_id = $1', tbl) USING target;
  END LOOP;
  DELETE FROM stores WHERE id = target;
END $$;
```

⚠️ **複数店舗をまとめて消すときは** `targets uuid[] := ARRAY[...]` にして
`FOREACH target IN ARRAY targets LOOP` で上のチェックごと回す。
**チェックをループの外に出さないこと**（1件目だけ検査して2件目が素通りする）。

### 🚨 実行するタイミング

**営業中は絶対にやらない。** KYOUKANOは夜が営業時間。
技術的にはKYOUKANOに影響しない（削除条件が `store_id = 特定UUID` で、
本番の `4cb3383a-…` とも PIN時代の `store_id IS NULL` とも一致しない。
`stores` を参照するCASCADEは `store_members` のみ）。
