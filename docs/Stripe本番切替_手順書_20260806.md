## 戻し方（何かおかしくなったら）

Supabase Secrets の3つを**テスト用の値に戻す**だけで、課金は止まります。
コードは戻さなくてよい（テストキーならテストモードで動くだけ）。

`stripe-checkout` を旧版に戻す場合：
```
git show <前のコミット>:supabase/functions/stripe-checkout/index.ts > supabase/functions/stripe-checkout/index.ts
supabase functions deploy stripe-checkout --project-ref qgcgkrcrfzonmmygcdju
git checkout supabase/functions/stripe-checkout/index.ts
```

## 注意点

- **`APP_URL`** が未設定なら既定の `https://shiftlink-app.jp` が使われる。`www.` へ307転送されるので
  動作はするが、設定するなら `https://www.shiftlink-app.jp` が正確。
- 入金の確定に **0〜3営業日**かかる（Stripeの表示）。期限ぎりぎりの振込は着金が遅れうる。
- 振込手数料は店舗負担。特商法ページに記載済み。
- 10店舗埋まったら `STRIPE_PRICE_ID` を16,280円のIDに差し替える。
  **同時にLP・特商法ページのキャンペーン記載も消すこと**（書いてあるのに適用しないのは景表法上まずい）。
