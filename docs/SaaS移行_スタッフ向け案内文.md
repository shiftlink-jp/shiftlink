# スタッフ向け案内文（LINE配信用・そのままコピーして使えます）

※招待リンク方式に対応（2026-08-03 更新）。店舗コードの手入力は不要になりました。

---

## 📱 配信用（1回目・事前告知）

```
おつかれさまです🌸

近日中に、シフトアプリのアドレスが新しくなります。
みんなに1回だけ、5分ほどの切り替えをお願いします🙏

【いつ】出勤したときに、その場で一緒にやります
【時間】5分くらい
【やること】リンクをタップして、いつものPINを入れるだけ

⚠️お願い⚠️
今のアプリは、まだ消さないでください！
新しいほうが落ち着くまで、両方残しておきます。

PINは今までと同じです。
不安なことがあったら気軽に聞いてください😊
```

## 📱 配信用（2回目・切り替え当日）

```
おはようございます☀️

新しいシフトアプリに切り替えます。
下のリンクをタップして、案内どおり進めてください。

👉 （ここに招待リンクを貼る）

📌 大事なこと4つ

① リンクを開いたら、右下の「…」から
　【Safariで開く】を選んでください🙏
　（LINEの中のまま進めると、あとでやり直しになります）

② Safariで開いたら「ホーム画面に追加」をしてください
　（やらないと、しばらく使わないうちにログインが外れます）

③ ホーム画面のアイコンから開いて、
　セラピストログイン → 自分の名前 → PIN（今までと同じ）

④ 今のアプリはまだ消さないでください

指紋・顔認証は、新しいほうでもう一度だけ登録が必要です。
わからなければ出勤時に一緒にやります！
```

---

## 👥 対面での作業手順（1人5分）

1. **招待リンクをタップ**（LINEで開いた場合は「Safariで開く」に切り替える）
2. **「ホーム画面に追加」**（Safariの共有ボタンから）
   - ⚠️ ここを飛ばすと、7日間使わないうちにログイン情報が消えます
3. **ホーム画面のアイコンから起動し直す**
4. 「この端末を登録しています…」→ 自動でログイン画面へ（**店舗コードの入力は不要**）
5. **セラピストログイン → 自分の名前 → PIN**（今までと同じ）
6. **指紋／顔認証を登録**
7. **通知を「許可」**
8. **確認**：今日のシフトが表示されるか／通知テストが届くか

## ❓ よくある質問

**Q. PINは変わりますか？**
A. 変わりません。今までと同じです。

**Q. 前のアプリは消していい？**
A. まだ消さないでください。1〜2週間ようすを見てから案内します。

**Q. 指紋認証をもう一度登録するのはなぜ？**
A. 指紋・顔認証はアドレスごとに登録される仕組みで、引き継げないためです。1回だけお願いします。

**Q. 通知が2回来るんだけど？**
A. 前のアプリと新しいアプリの両方に通知が入っているためです。前のアプリを消せば直ります。

**Q. リンクは毎回いるの？**
A. 最初の1回だけです。次からはホーム画面のアイコンから、PINだけで入れます。

**Q. 「店舗コードを入力してください」と出た**
A. リンクの有効期限が切れているか、新しいリンクが発行されています。オーナーに最新のリンクを聞いてください。

## 🔑 オーナー向けメモ

- 招待リンクは **管理 → 店舗 → 端末の管理 → 「招待リンクを発行する」** で発行
- **14日有効・何人でも使える**
- **再発行すると前のリンクは即座に無効**になる
- **全員の移行が終わったら、もう一度発行して古いリンクを無効化する**（忘れると14日間有効なまま）
- 移行後は **端末の管理** に実際に使っている端末だけが並ぶ。見覚えのない端末があれば「×」で解除
- 緊急復旧用コードは**オーナーだけが保管**（スタッフには配らない）
