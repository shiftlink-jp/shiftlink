## 4. Claude Code実装時の申し送り

- 見出し・本文・Q&Aはすべて実HTML。上記2章の見出し階層（h1×1、h2×11、h3）をそのまま使う
- alt属性は「情報を持つ画像のみ」自然文＋キーワード1〜2個。装飾画像はalt=""
- Q&AセクションはFAQPage構造化データ（schema.org）の実装を検討（AI検索・リッチリザルト対策。今回は仕様提示のみ、実装要否は追って判断）
- アニメーションはIntersectionObserver＋CSS transitionで軽量に。`prefers-reduced-motion`時は簡略化
