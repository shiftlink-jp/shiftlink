# ShiftLink LP 画像生成プロンプト集【白×オレンジ版】

最終更新: 2026-07-25
狙い: 現在完成している `01-hero.png`（白背景×オレンジのプレミアム路線）を"世界観の正解"として固定し、
残り9枚（02〜10）をChatGPT（画像生成）で**継ぎ目なく**作る。

> 前回（7/23）は濃紺×ゴールドの高級路線で21枚案を作成したが、実際に採用されたのは
> 白×オレンジのデザイン（`01-hero.png`）。今回はそちらに統一する。
> 対象は既存の `lp/index.html` が参照する9ファイル: `02-problems.png` 〜 `10-faq-footer.png`。

---

## なぜ継ぎ目が目立つのか

8枚をバラバラに生成すると、ChatGPTは毎回「初期状態」からデザインを作るため、
背景の余白・角丸の半径・オレンジの濃さ・フォントの太さが微妙にズレます。
対策は1つだけです。**「前の画像」を毎回アップロードして「これと寸分違わず揃えて」と言い続けること。**
言葉の指定だけでは絶対に揃いません。画像そのものを参照させるのが唯一の解決策です。

---

## 進め方（重要）

1. 新しいChャットを1つだけ開く（章ごとに分けない。分けると世界観がリセットされる）
2. **最初のメッセージで `01-hero.png` を添付**し、下記「STEP 0」を貼る
3. OKが返ってきたら、02→03→04…の順で1枚ずつ、そのつど**直前に生成した画像を添付し直して**プロンプトを送る
4. 生成物は毎回目視チェック（下部「生成後チェックリスト」参照）

```
添付した画像は、開発中のランディングページ「ShiftLink」（メンズエステ店舗向け経営管理アプリ）
の1枚目（ファーストビュー）です。

これから、この画像と完全に同じデザインシステムで、残り9枚を順番に作ってもらいます。
毎回この添付画像を「正解」として、色・余白・角丸・フォント・装飾のトーンを寸分違わず揃えてください。

■ この画像から読み取ってほしいデザインルール
・背景：白、隅にごく薄いオレンジ色の円形のぼかし装飾（オーガニックな滲み。直線的な罫線は使わない）
・メインカラー：オレンジのグラデーション（ロゴ・CTAボタン・強調数字・アイコンに使用。彩度の高いオレンジ〜やや赤みのオレンジ）
・文字色：見出し・本文は黒に近いダークグレー。青は「利益」など信頼性を示す数字だけに使う特別な差し色
・書体：ゴシック体のみ。明朝体・セリフ体は使わない
・カード／数値ボックス：白背景、薄いグレーの境界線、やや大きめの角丸、柔らかい影
・スマートフォンのモックアップ：実機に近いリアルなフレーム（金属ボディ・ノッチ・影）。
　画面内はこの添付画像と同じ書体・同じUIコンポーネントのスタイルで作る
・CTAボタン：オレンジのグラデーション横長ボタン、白文字太字、右向き矢印アイコン、丸みのある角
・バッジ：白背景＋細いオレンジ枠のピル型、左にアイコン
・全体の余白：ゆったり。詰め込みすぎない

■ 比率
縦長のランディングページを1セクションずつ画像化しています。横幅はこの添付画像と同じにし、
上下につながって見えるよう左右の余白幅を必ず揃えてください。

■ 禁止
・添付画像にない色を増やさない（オレンジ・黒〜グレー・差し色の青の3系統のみ）
・金の罫線、濃紺、明朝体など「別の世界観」（別案として検討したことがある高級路線）を絶対に混ぜない
・絵文字、ネオン、パステル、丸っこいポップな書体
・指定していない金額・割引・実績・お客様の声を追加しない

準備ができたら「OK」とだけ返答してください。2枚目から順に送ります。
```

# トラブル対応（そのまま追加で貼る）

| 症状 | 追加で貼る文 |
|---|---|
| 前の画像とトーンが違う | 「1枚目に添付した画像と全く同じ配色・余白・角丸・フォント・装飾で作り直してください。」 |
| 上下がつながらない | 「これは縦長LPを分割した1枚です。左右の余白幅と背景装飾の位置を、添付画像とぴったり揃えてください。」 |
| オレンジの色味がズレる | 「オレンジは添付画像と全く同じ彩度・グラデーションにしてください。黄色すぎる／赤すぎるオレンジは禁止です。」 |
| 日本語が崩れる | 「文字が正しく描画されていません。指定した日本語を一字一句そのまま正確に描き直してください。」 |
| 装飾が多すぎて安っぽい | 「添付画像と同じ、余白を活かした落ち着いたトーンにしてください。装飾を減らしてください。」 |
| 明朝体や金色など別の世界観が混ざった | 「濃紺やゴールド、明朝体は使わないでください。添付画像と同じ、白背景×オレンジ×ゴシック体だけで作り直してください。」 |

# 生成後チェックリスト

1. 01〜10を並べて通しで見て、境目で「あ、変わった」と感じる箇所がないか
2. 漢字が化けていないか（特に「委託金」「予約」「無料」）
3. 料金が「14,800円（税抜）」「16,280円（税込）」「1日約490円」の3つだけになっているか
4. 08の先着枠・特典内容が実際に提供可能な内容か（ダミーのまま出さない）
5. 架空の実績・お客様の声・受賞歴が紛れ込んでいないか
6. `lp/images/` に配置し、`lp/index.html` のファイル名と一致しているか
7. 各 `<img>` の `alt` にセクションの見出し文言が入っているか（画像だけのLPは検索に載らないため）
8. stagingで確認 → 問題なければmainへマージ
